# Guys vs Gals art

All of these are from Microsoft's Fluent Emoji (3D style), https://github.com/microsoft/fluentui-emoji, MIT License,
Copyright (c) Microsoft Corporation. The Apple TV app has the same pictures in `tv-app/FamilyGameNight/Assets.xcassets/Gvg*`.

| File | Fluent Emoji asset | Changes |
| --- | --- | --- |
| guys-hero.png | Man superhero (default skin tone, 3D) | none |
| gals-hero.png | Woman superhero (default skin tone, 3D) | the blue suit recoloured pink |
| bolt.png | High voltage (3D) | none |
| trophy.png | Trophy (3D) | none |
| crown.png | Crown (3D) | none |

The lettering is Bangers (SIL Open Font License, Google Fonts); the Apple TV app ships `GameNight/Fonts/Bangers-Regular.ttf`.

## Our Pics pictures

Everything in `../pics/` (and `Assets.xcassets/GvgPic-*` in the Apple TV app) is a Fluent Emoji 3D asset from the same
project, MIT License, shrunk to 200 pixels. Each file is named after its Fluent asset (for example `wrench.png` is
"Wrench", `high-heeled-shoe.png` is "High-heeled shoe", `nail-polish.png` is "Nail polish" in the default skin tone).
