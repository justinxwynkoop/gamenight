# Game Night

Family game night on the TV: **Jeopardy**, **Family Feud** and **Singo Night**. The game shows on the TV, everyone
plays from their phone, and the host runs it from a phone. One copy of the rules decides everything (buzzer order
included), so nobody's device can cheat.

Everything lives in this one repository:

- **The Apple TV app** "Family Game Night" ([`tv-app/`](tv-app/README.md)) runs the game, and ships to the family
  through TestFlight by itself.
- **The website** (`https://gamenight-one.vercel.app`) has the phone, host and editor pages, and a **TV page**
  (`/tv`) that runs the game in any browser, for a TV without an Apple TV.
- Phones talk to the TV through a free Supabase relay, so all you need is internet: no computer or server on your
  network. With no internet, [server mode](docs/SERVER-MODE.md) runs it all on a computer at home.

## Quick start

1. On the Apple TV, open **Jeopardy** or **Family Feud** (or open `<site>/tv` in a browser on the TV and pick one).
   The lobby shows a QR code and a 4-digit room code.
2. Players scan the QR code, or go to the site and type the code, then pick a name and colour.
3. The host opens `/host` on a phone (the TV shows how), types the room code and the **host PIN** from the TV's
   menu (Play/Pause on the Apple TV remote, or the corner **Menu** button on the browser TV), picks a question set
   and starts. Once a game starts, new players are kept out unless the host turns on **Let new players join** in
   Settings.
4. The host page's **Questions** tab is the question editor: write sets, or drag in a file.

Setting it all up the first time (Supabase, Vercel, the app) is in **[docs/ONLINE.md](docs/ONLINE.md)**.

## The pages

| Page | Who | Address |
| --- | --- | --- |
| Player | everyone's phone | `/` |
| Host | the host's phone or tablet; answers visible | `/host` (PIN) |
| TV | a TV with a browser (when there is no Apple TV) | `/tv` |
| Editor | whoever writes the questions | `/editor` (PIN) |

## What is in this repo

```text
tv-app/                 the Apple TV app (Swift; Jeopardy and Family Feud screens, Singo Night) and its docs
room.js, lib.js         the room: players, teams, scores, host controls (no sockets or files)
games/                  Jeopardy and Family Feud rules, one folder per game
engine/                 the hub, the online relay, and the entry points the Apple TV app and the browser TV load
public/                 the phone, host, editor and TV pages (public/relay/ is the online connection)
web/                    GENERATED by npm run build: the website Vercel serves; committed
data/<game>/            the question sets that ship with the game
docs/                   the documentation above
scripts/                build scripts, browser and live-relay checks, data helpers
test/                   node --test suites
server.js               server mode, the offline backup (Start Game Night.bat on Windows)
relay.config.json       the Supabase project URL and publishable key (public by design)
```

## Working on it

```bash
npm install
npm test          # rules, engine, relay, importer, importing
npm run build     # after any change outside tv-app/: rebuilds web/ and the Apple TV app's engine and sets (commit them)
npm run e2e       # the real pages in a browser (needs Playwright)
cd tv-app && swift test    # the Apple TV app's logic (on a Mac)
```

Changes go in through pull requests to `main`; see [CLAUDE.md](CLAUDE.md) for the house rules. Merging is going live:

| Workflow | Runs when | Does |
| --- | --- | --- |
| Test (`web.yml`) | anything outside the Swift code changes | tests, generated files up to date, real pages in a browser, a join through the real Supabase |
| Apple TV app (`tv-app.yml`) | the app, the rules or the engine change | `swift test` and a tvOS build on a Mac |
| Send to TestFlight (`testflight.yml`) | the same, merged into `main`; the 1st of every other month; by hand | builds, signs and uploads the app to TestFlight |
| Vercel | every push to `main` | deploys `web/` to the site |
